# 家聚 · JiaJu

独立的米家与海尔设备控制 Android 应用，当前发布版本 **0.0.12**。设备读取和已适配控制留在家聚内，不依赖官方 App、MiLink、LSPosed 或 Home Assistant 部署。

家聚由原「家控」独立开发版本更名而来，保留包名 `dev.homecontrol.app` 和发布签名，可覆盖升级并保留账号及展示设置。本项目与融合设备卡片 / HyperFusionWidget 分开维护。

## 当前功能

- 首页设备按每行两列展示，逐项选择常驻，数量不限；「更多设备」包含全部设备。
- 首页长按卡片拖动排序；编辑页以紧凑图标列表拖动排序，同步到首页及小组件。
- 编辑页按平台分别下拉筛选家庭与房间，筛选不影响首页已选设备；卡片保留来源与位置说明。
- 四种展示方式：首页、更多、隐藏、不展示。不展示设备仅在编辑页汇总管理；空隐藏栏目不占位。
- 隐藏设备和不展示设备归为一组，与上方设备选择区域以分割线区分。
- 账号管理、关于、桌面小组件和负一屏添加指引集中在设置中。
- 灯具电源、亮度/色温滑块、颜色与模式；已适配床头灯提供延时关闭和周期定时入口。
- 已适配电饭煲、微波炉提供模式、参数设置、食谱推荐/搜索、食材步骤及收藏页面。
- 海尔已适配油烟机提供电源、照明和风速控制面板。
- 摄像头提供 App 内视频页、播放/暂停、重连、清晰度与横屏全屏；针对 `chuangmi.camera.069a01`、`chuangmi.camera.039c01` 和 `xiaomi.camera.c302` 接入独立 MISS/CS2 与 Android 硬件解码。画面设置按型号分别映射夜视、翻转、水印和指示灯，`c302` 支持四档旋转角度菜单。
- 监控按当前网段选择起播路径；外网不先等待局域网超时，已同步设备不再逐次刷新全目录。
- 监控持续消费控制应答，并处理媒体会话续期；修复观看约两分钟后协议队列可能溢出的中断。
- 设备控制面板刷新时保留控件，离线或读取失败保留卡片和上次状态，不自动重发控制命令。

- 插座的用电数据收为可横向查看的单行小字，常用页保留开关、指示灯；循环任务、倒计时和保护参数集中到更多，统一使用应用配色的编辑面板，后台读取保留控件。
- 空调常用页显示单行用电数据、开关、模式、目标温度、设备支持的风向/扫风和风速，其余功能收进更多。
- 监控竖屏画面下方提供对话、截图、录像、视角移动、回看和存储管理；更多设置包含摄像机设置、存储卡状态/录制模式和 NAS 访问设置。截图保存在 Pictures/JiaJu，录像保存在 Movies/JiaJu；当前录像只包含视频。
- 对讲只在用户按住或主动点击后启动，首次需要麦克风权限，松开、暂停、连接出错或离开页面停止；按设备实际音频格式编码。存储卡回看先匹配录像目录里的准确片段，再请求播放。

## 使用与范围

首次在设置中自行登录米家或海尔账号。米家在小米官方网页完成登录和验证；海尔支持密码及网页授权入口。账号地区须与设备所在地一致。服务会话加密保存在手机 Android Keystore 对应的文件中，不保存账号密码，不备份到源码或 NAS 续接包。

本项目仍在开发，功能按具体型号适配，不能视为完整复刻米家：

| 范围 | 当前状态 |
| --- | --- |
| `yeelink.light.bslamp2` | 灯具面板、延时与周期定时入口；此前完成真实开关测试 |
| `chunmi.cooker.normal2` | 基础/扩展模式、自选菜单和参数预览 |
| `chunmi.cooker.js5` | 基础模式按该型号枚举适配，扩展程序尚未验证 |
| `xiaomi.microwave.cm20l` | 六类主入口、分组菜单、时间/火力或份量与预计时长 |
| 海尔 IQ75Z1 油烟机 | 独立会话、目录、状态与控制；部分控制由早期用户实测 |
| `chuangmi.camera.069a01` | 独立视频页及局域网/跨网络连接代码；跨网络 H.265 视频已实测接收解码，真实视频页持续渲染及退出断开通过；对讲测试音由用户确认出声；云台移动仍待现场确认 |

停止米家进程后，独立设备/食谱读取已验证。270 项本地检查通过；本次界面改版没有下发实体指令。烹饪、真实定时执行、收藏写入、跨地区及长期会话仍需进一步实测。本次界面改版已覆盖安装，确认保留米家登录、50 台米家及 1 台海尔缓存；15 项原生界面检查通过，确认四个家庭与 46 台设备的位置数据，首页长按拖动已由用户手动确认成功，临时展示设置已恢复，家庭/房间依赖云端返回的数据；分类读取失败会保留旧信息。厨房预约仍需独立适配。0.0.8 的连续播放、帧节奏及全屏结果见 [摄像头验证记录](docs/VALIDATION-0.0.8.json)；25 秒真实窗口测试约 20 帧/秒，最长呈现间隔 69 毫秒。没有录制或保存画面，不能据短测保证所有网络长期流畅。详情见 [验证记录](docs/VALIDATION-0.0.6.json)。

0.0.9 针对「打开后很久才有画面」优化起播，当前异网真实页面短测约 2.4 秒出首帧；这不是所有网络下的速度保证，也不等同于端到端实时性测量。详见 [起播验证](docs/VALIDATION-0.0.9.json)。

0.0.10 的取流修复已完成三分钟原生播放验证（3596 帧、17 条控制应答）。短时连接复用与自动恢复代码已保存，因手机断开导致验收未完成，**发布版默认关闭**。2026-11-06 的 Windows 同签名重建版已覆盖安装，真实视频页三分钟持续渲染至 3619 帧，收到 18 条控制应答，全屏、返回及退出断开通过；本次结果见 [Windows 实机验证](testing/device-20261106-1929/result.json)，原发布验证与待办见 [0.0.10 记录](docs/VALIDATION-0.0.10.json)。

0.0.11 本机开发版已覆盖安装，当前四台在线摄像头均完成真实页面出帧、全屏、画面设置菜单和退出释放检查。新增两型号分别保留三分钟测试记录；最终包另完成逐台回归，其中另一台 `069a01` 连续观看三分钟。前期仍出现过起播失败，修正目录重发并增加有界备用媒体候选后保留完整结果；不保证所有网络下无超时或固定帧率。该轮离线设备、新型号高清、声音与云台尚待验证，详情见 [0.0.11 验证与限制](docs/VALIDATION-0.0.11.json)。

0.0.12 的界面、合成媒体、NAS 只读状态和实机回看结果见 [本轮验证记录](docs/VALIDATION-0.0.12.json)。对讲测试音不等同于麦克风双向通话验收；NAS 写入与长期备份、其它摄像机的回看和云台物理效果仍需继续验证。

## 构建与继续开发

从 GitHub 接续开发请先阅读 [v0.0.12 续接说明](docs/CONTINUE-0.0.12.md)，包含版本定位、构建步骤、验证边界与下一步待办。

环境：Python 3.9+、Git、JDK 17、Android SDK platform 35 / build-tools 36.0.0、Go 1.26+、Android NDK r26+。当前视频原生组件仅构建 arm64-v8a。构建不使用 Gradle；测试 JSON 运行库已附在 `tests/lib`，校验后仅用于本地测试，不打进 APK。

```sh
python3 tools/Build-JiaJu.py --check
python3 tools/Build-JiaJu.py
```

先按 [CONTINUATION.md](CONTINUATION.md) 配置工具链与自己的签名，或恢复维护者的私有 NAS 续接包。缺省产物为 `dist/JiaJu-0.0.12.apk`，本机可另配输出目录。公开仓库和 Release 不包含签名私钥、密码、账号会话或手机数据。

Windows 可直接使用 PowerShell 和 Windows 版 JDK/SDK/Go/NDK，将命令中的 `python3` 改为 `python`。本机路径与输出目录在 `local/build-environment.json` 中设置；便携工具链可保存在 `tools/toolchains/`。
